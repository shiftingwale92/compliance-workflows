# Consent notice checklist (DPDP s.5, Rule 3) - last checked 28 October 2026
- [ ] Names the personal data being collected, in a notice understandable independently of any other information (Rule 3(a))
- [ ] States the specific purpose, one purpose per line, with an itemised description of the data and the goods/services enabled (Rule 3(b))
- [ ] Explains how to withdraw consent (s.6(4)) and seek grievance redressal (s.13), with the link/means to do both (Rule 3(c))
- [ ] Explains how to complain to the Data Protection Board
- [ ] Language option offered: English or any Eighth Schedule language (s.5(3)); consent request in clear plain language with the same option and DPO/authorised contact details (s.6(3))
- [ ] Plain language, tested with a non-lawyer
- [ ] Version number and date on the notice itself
- [ ] Consent control is unticked by default, purpose-level, no bundling
- [ ] Withdrawal path exists and is as easy as giving consent (s.6(4))
